# Hiring Analyzer Extension

For resume reviews, use the bundled `skills/hiring-analyzer/SKILL.md` workflow. It defines seven evidence-based perspectives, fact-preserving revision, and unresolved-question tracking.

Use isolated reviewers only when available and permitted; otherwise disclose sequential perspective passes in a shared context. Follow the skill for verdicts, evidence limits, and output files. This extension does not establish actual ATS compatibility or guarantee hiring outcomes.
