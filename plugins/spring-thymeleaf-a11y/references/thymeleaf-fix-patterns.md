# Thymeleaf Fix Patterns

## 이미지 대체 텍스트

- 룰 예시: `image-alt`
- 권장 수정:
  - `th:src`를 사용하는 이미지에 의미 있는 `alt`를 채운다.
  - 장식용 이미지는 `alt=""`로 명시한다.

## 폼 필드 레이블

- 룰 예시: `label`
- 권장 수정:
  - `label[for]`와 필드 `id`를 연결한다.
  - `th:field` 사용 시 실제 렌더링 id가 기대와 같은지 확인한다.
  - 공통 fragment 내부 입력 폼이면 여러 페이지 영향 범위를 확인한다.

## 버튼 이름

- 룰 예시: `button-name`
- 권장 수정:
  - 텍스트 버튼은 보이는 텍스트를 유지한다.
  - 아이콘 버튼은 `aria-label` 또는 숨김 텍스트를 추가한다.

## 문서 언어와 제목

- 룰 예시: `html-has-lang`, `document-title`
- 권장 수정:
  - 공통 레이아웃의 `html lang`을 선언한다.
  - 페이지별 `title`을 동적으로 주입한다.

## 수정 경계

- 안전한 자동 수정:
  - `alt`
  - 명확한 `label`-`id` 연결
  - 기존 텍스트 기반 버튼 이름 보강
- 수동 검토 우선:
  - 랜드마크 구조
  - 헤딩 순서
  - 링크 텍스트 의미 개선
  - 커스텀 위젯 ARIA
